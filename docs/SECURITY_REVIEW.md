# 公開前レビュー

確認日：2026-09-05。対象：現時点のソース、依存ライブラリ、public、生成したdist。侵入テストや安全性の保証ではありません。

## 確認結果

- APIキー・GitHubトークン・秘密鍵の典型的な形式を検索し、対象ファイルに該当なし。環境変数ファイルや秘密鍵ファイルも見つからなかった。
- 開発者のローカルパス、開発者名、確認に使ったLANアドレスをソース・公開ファイル・ビルド出力から検索し、該当なし。
- 学習記録はlocalStorage。バックアップは利用者が手動で保存・読み込むJSONで、アプリから外部へ送信する処理はない。解析・広告SDKも見つからなかった。
- サーバAPI、ログイン、データベース、課金機能はない。公開するのは静的なビルド出力で、開発サーバは公開しない。
- Reactの通常のテキスト描画を利用。アプリソース内にdangerouslySetInnerHTML、innerHTML、eval、new Functionの使用は見つからなかった。バックアップの値をHTMLとして実行する処理はない。
- 公開対象605ファイルの内訳：JPEG 522、PNG 79、PDF 3、SVG 1。画像のEXIFを確認し、JPEGの記録は画像の縦横サイズのみ。GPS・撮影者等のEXIFは見つからなかった。画像を全数目視して個人情報不存在を保証したものではない。
- 3件のPDFはIPA試験資料。pdfinfoではJavaScript・フォームなし。タイトル・生成ソフト等の元資料のメタデータはある。
- distにソースマップ、環境変数ファイル、.DS_Storeはなかった。学習記録・ブラウザの保存領域はビルド対象に含まれない。

## 対応した問題

- npm auditでVite（high）とesbuild（moderate）の計2件を検出。開発サーバに関する既知の問題で、静的配信ではそのサーバは動かないが、開発環境も含めて更新した。
- Vite 7.3.6系、対応するReactプラグインへ更新。更新後のnpm auditは0件。型検査・教材検証・本番ビルド成功。
- .gitignoreに環境変数、秘密鍵、作業用設定、ログ、バックアップの除外を追加。ただしignoreは公開内容の監査の代替にはならない。
- 外部遷移時のRefererを抑制するmetaタグを追加。

## 公開すると分かるもの

- 公開リポジトリの所有者アカウント、プロフィール、公開コミット情報。コミットには実名や私用メールアドレスを使わず、公開用名とGitHubのnoreplyメールを使用する。
- コード・教材・解答。秘密にすべき認証情報をクライアントへ入れない設計が前提。解答の秘匿が必要な試験サービスではない。
- 配信元にはアクセスに必要なIPアドレス等が届く。アプリが答案を送信しないことと、配信事業者が通信情報を扱わないことは別。

## 公開時の条件

- GitHub PagesのHTTPSを有効にする。
- 初回は公開に必要なファイルを明示的に選ぶ。作業ログ、スクリーンショット、エージェント設定、個人バックアップは含めない。公開前にGitのステージ内容とコミットの著者情報を再確認する。
- GitHubアカウントを多要素認証で保護する。アカウント設定の確認・変更はこのレビューでは行っていない。
- npm auditの再実行と定期更新を続ける。0件は未発見の脆弱性がないことを意味しない。
- 同一GitHub Pagesオリジンの別サイトとlocalStorageの分離はできない。信頼できない別アプリを同じオリジンへ配置しない。
- 原典の出典・改変表示を維持する。書籍サンプルは公開用ファイルに見つからなかったが、全解説の著作権・内容の正確性を今回だけで保証しない。

## 公開後も残る制約

記録は端末・ブラウザ・URLごとに保存される。データ消去で失われるため、バックアップが必要。共有端末では他の利用者も記録を見られる。答案欄に個人情報・実業務の秘密を書かない。アカウント同期や秘密情報の保存が必要になった場合は、認証とサーバ保存を別途設計する。
