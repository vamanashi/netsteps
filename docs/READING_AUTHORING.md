# 原文を少しずつ読み、章末で原問を解く

平成30年度 秋期 午後Ⅱ 問1を先行対象とする。ほかの年度へは自動展開しない。
既存の段階学習は補助として残し、原文の理解に必要なときだけ戻れるようにする。

## 1区切りの構成

- 読む観点を一つ示す。まだ提示していない原文を読んだ前提にしない。
- 初出の用語は短く補足する。原文の代わりに要約だけを読ませない。
- 本文は原PDFと照合したテキストとして表示する。要約や言い換えではなく、原文の語句・条件・空欄・下線番号を保ち、印刷上の改行・字間だけを整える。
- 図表は原画像を切り出す。凡例・キャプション・脚注も含め、本文の文章まで画像に含めない。
- 文や箇条書きの途中では切らない。ページをまたぐ文も結合する。前の条件や主語が必要なら、直前の原文を「前の文脈（原文の再掲）」として重ねて示す。
- 直後に、表示中の原文だけで答えられる理解チェックを置く。
- 正誤と理由を示し、次の区切りへ進む。正解や実機操作を移動条件にしない。

章末には、その章までの読解で必要条件が揃う原問を配置する。
対応する設問の原文だけを表示し、読んだ本文・図表を参照欄から再表示できるようにする。
章ごとの答案は原問全体の解答記録に直接蓄積する。読解チェックとは別に数える。
全ての原問を解答・自己採点して確定したら完了する。最後の全文再挑戦は必須にしない。
解答済みと全問正解、補助ありと独力解答を混同しない。

## データ

`src/content/readings/{examId}-{division}-q{number}.json` に配置する。
型定義は `src/content/readings.ts` の `ReadingPlan` を参照する。

- `examKey` は `originals.json` に存在する原問キー。
- `chapters[].targets` に原問の小問IDを列挙する。全小問を一度ずつ配置する。
- 導入の章のみ `targets: []` としてよい。
- `parts[].regions` の `page` はファイル名NNと同じ冊子ページ番号。
- `top` / `bottom` は原画像上端からの0〜1の割合。
- 本文を原文順に網羅し、脚注・凡例・表の見出しを落とさない。
- 図が長い場合は意味のある小図単位に分け、登場人物や列の意味を補足する。
- 問題文中の空欄は埋めずに表示する。章末で原問を解く。
- 各区切りのIDは公開後に別内容へ再利用しない。保存された理解チェックとの対応に使う。

原文テキストは `src/content/reading-transcripts/*.json` に分離する。
`examKey` と `parts`（区切りIDをキー）または `questions`（小問IDをキー）を持つ。
各値の `blocks` は本文順の `text` / `figure`。本文には `text` と出典の `pages`、図表には `page` / `top` / `bottom` / `caption` を指定する。
必要な再掲文は `context: [{text, pages}]` に指定し、新しく読む本文と区別する。
下線は原文と同じ範囲を `underlines: ["本文と一致する文字列"]` で指定する。範囲を広げたり、正解だけを強調したりしない。
空欄の四角枠は［ア］などで表す。答えを埋めない。OCRをそのまま採用せず、原画像を目視照合する。
`parts[].regions` は原画像との照合用として残す。通常表示はテキストと図表のみにし、元の切り出しは折り畳む。
読解本文だけでなく、章末の全小問も同様にテキスト化する。

読解記録は `netsteps-v3.readings[examKey]`、原問答案は既存の `exams[examKey]` に保存する。
従来の `units` の補助練習記録は削除しない。バックアップに全て含める。

## 検証

`npm run validate` で参照・順序・原問全小問の割当て・全区切りと全小問のテキスト有無を検査する。
構造検査だけでは、文字や図の切断、原文の欠落、説明の難しさは判定できない。
原画像を目視し、表示する領域の上下境界を確認する。
さらにスマートフォン幅で、原図の拡大・前後移動・回答復元・章末解答の合算を操作する。
